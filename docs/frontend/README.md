## 概要

- **目的**
	- このフォルダはフロントエンドの機能仕様と設計に関する資料を集約します。画面構成、主要機能、非機能要件、UIコンポーネントの仕様などを確認するためのドキュメント群です。

- **利用方法**
	- フロントエンド開発開始時、UI実装時、機能追加時に参照してください。まず `frontend_spec.md` で全体の機能要件と画面構成を把握してください。

## ファイル構成

### 主要ファイル
- [frontend_spec.md](frontend_spec.md) — フロントエンド機能仕様書（画面一覧、主要機能、非機能要件）。
- [README.md](README.md) — この案内ファイル。

## 補足 / 運用

- ドキュメントは随時更新してください。画面追加や機能変更がある場合は変更箇所と理由を追記してください。
- 実装の詳細なガイドラインやコーディング規約については `docs/develop-guide/` や `docs/standards/` を参照してください。
- バックエンドとの連携仕様については `docs/architecture/` のAPI層やサービス層の設計を確認してください。
