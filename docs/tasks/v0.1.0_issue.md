## 概要
サービス層とデータアクセス層（Repository）の抽象インターフェース（ABC）を定義し、後続実装の設計指針を確立します。

## 詳細

### 実装内容

#### 1. サービス層抽象クラス (`app/services/base.py`)
- `BaseService` 抽象クラス定義
- 共通メソッドの定義（CRUD操作の基本形）
- トランザクション管理インターフェース

#### 2. Repository抽象クラス (`app/repositories/base.py`)
- `BaseRepository` 抽象クラス定義
- 基本CRUD操作の抽象メソッド:
  - `get(id)`: 単一取得
  - `get_multi(skip, limit)`: 複数取得
  - `create(data)`: 作成
  - `update(id, data)`: 更新
  - `delete(id)`: 削除
- フィルタリング・ソート用インターフェース

#### 3. スキーマ定義雛形 (`app/schemas/base.py`)
- Pydantic BaseModelを継承した基底スキーマ
- 共通フィールド（id, created_at, updated_at）
- リクエスト/レスポンススキーマの雛形

#### 4. 依存性注入パターンの雛形
- `app/dependencies.py`: FastAPI依存性注入の設定
- Repositoryインスタンスの取得関数

### 影響範囲
- `app/services/base.py`
- `app/repositories/base.py`
- `app/schemas/base.py`
- `app/dependencies.py`

### 技術的な考慮事項
- Python ABC (Abstract Base Class) を使用
- 型ヒント（Type Hints）を活用
- Generic型でRepositoryを抽象化
- FastAPIの依存性注入システムと統合
