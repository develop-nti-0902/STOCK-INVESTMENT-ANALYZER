## 概要
`stock_basic_info` のデータ取得・変換・保存を担当する Service 層を実装します。具体的には以下のコンポーネントを作成します:

- `converter.py` : yfinance の raw データを Pydantic / DB モデルに変換
- `fetcher.py`   : `yfinance.Ticker` を使ってデータを取得するロジック
- `saver.py`     : Repository を使い DB 保存（insert/update）を行う
- `service.py`   : 上記を纏めるユースケース実装（stock_master から銘柄取得→fetcher→converter→saver）

※ 機能要件:
- `stock_master` から銘柄を取得して yfinance からデータを収集・保存する機能
- 特定のシンボルを指定して DB からデータを取得する機能

## 実装レイヤー
- [x] Service 層
- [x] Infrastructure（yfinance 呼び出し）

## 実装内容

1. `app/services/stock_basic_info/` ディレクトリを作成し、`converter.py`, `fetcher.py`, `saver.py`, `service.py` を追加
2. `fetcher` は同期的な yfinance 呼び出しを非同期にラップするか、適切に Executor を使って実装
3. `service` はバッチ起動用と単一シンボル取得用の公開メソッドを提供（例: `fetch_and_save_all()`, `get_by_symbol(symbol)`）

## テスト計画
- 単体テスト: `tests/unit/services/test_stock_basic_info_service.py` を作成
- モック: yfinance 呼び出しはモック化して動作検証

## 完了条件
- 各モジュールが実装され、主要なパス（全件取得→保存、単一取得）がテストでカバーされていること
