# v0.9.0 - EDINET 貸借対照表取得機能 Issue一覧

## 概要
EDINET APIとの通信、XBRLファイルの解析、一時ファイル管理などの共通処理を実装します。これらは他のEDINETデータ取得機能でも再利用可能な基盤となります。

## 実装レイヤー
- [x] Service 層（core）
- [x] Infrastructure（EDINET API, XBRL）

## 実装内容

### 1. 共通パーサー基盤
- `app/services/core/parsers/base_parser.py`: 基底パーサークラス
  - 抽象メソッド: `parse(data: Any) -> Dict[str, Any]`, `validate_data(data: Any) -> bool`
- `app/services/core/parsers/xml_parser_mixin.py`: XML解析用Mixin
  - メソッド: `parse_xml(file_path: str)`, `extract_text(element, xpath, namespaces)`
  - 依存ライブラリ: lxml

### 2. 共通ファイル管理基盤
- `app/services/core/file_managers/base_file_manager.py`: 基底ファイルマネージャークラス
  - 抽象メソッド: `create_temp_directory(*args, **kwargs) -> Path`, `cleanup(path: Path) -> None`
- `app/services/core/file_managers/temp_file_manager_mixin.py`: 一時ファイル管理用Mixin

### 3. EDINET API クライアント
- `app/services/market_data/edinet/common/api_client.py`: EdinetAPIClient
  - RetryMixinを継承（リトライ機能）
  - httpxを使用した非同期HTTPクライアント
  - メソッド:
    - `search_documents(target_date: date, doc_type: int = 2) -> List[Dict]`: 指定日の書類一覧取得
    - `download_document(doc_id: str) -> bytes`: 書類ダウンロード（ZIPファイル）
  - レート制限: 0.5秒間隔、リトライ最大3回

### 4. XBRL ユーティリティ
- `app/services/market_data/edinet/common/xbrl_utils.py`: XBRLUtils
  - クラス変数: `NAMESPACES`（XBRL名前空間の辞書）
  - 静的メソッド:
    - `find_xbrl_files(extract_dir: str) -> List[str]`: XBRLファイル探索
    - `extract_contexts(root: etree._Element) -> Dict[str, str]`: contextを抽出

## 技術スタック
- httpx: 非同期HTTPクライアント
- lxml: XML/XBRL解析
- pathlib: ファイルパス操作

## テスト計画

## 実装内容

1. `app/repositories/edinet_balance_sheet_repository.py` を作成
2. BaseRepositoryを継承し、以下のメソッドを実装:
   - `find_latest_by_sec_code(sec_code: str)`: 指定銘柄の最新データを取得
   - `find_by_period(sec_code: str, period_end_date: date)`: 指定銘柄・期間のデータを取得
   - `find_by_doc_id(doc_id: str)`: 文書IDでデータを取得
   - `upsert(data: dict)`: UPSERT処理を実行（submission_date比較付き）

   - UNIQUE制約: (sec_code, period_end_date)

## 概要
EDINET から貸借対照表データを取得・解析・保存する Service 層を実装します。具体的には以下のコンポーネントを作成します:

- `fetcher.py`: EDINET書類のダウンロード・解凍
- `parser.py`: XBRLファイルから貸借対照表データを抽出（当期+過去4年分の計5年分）
- `file_manager.py`: 一時ファイルの管理（作成・削除）
- `service.py`: 上記を纏めるユースケース実装

## 実装レイヤー
- [x] Service 層
- [x] Infrastructure（EDINET API, XBRL解析）

## 実装内容

### 1. EdinetDocumentFetcher（fetcher.py）
- BaseFetcherを継承
- 依存: EdinetAPIClient
- メソッド:
  - `fetch(doc_id: str) -> Path`: 1件取得
  - `fetch_batch(doc_ids: List[str]) -> List[Path]`: 複数並列取得
  - `download_document(doc_id: str) -> Path`: ダウンロード・解凍の実処理
  - `search_documents(target_date: date, doc_type: int = 2) -> List[Dict]`: 書類検索
  - `validate_identifier(identifier: str) -> bool`: doc_idの形式検証

### 2. EdinetBalanceSheetParser（parser.py）
- BaseParser, XMLParserMixinを継承
- 依存: XBRLUtils
- メソッド:
  - `parse(xbrl_file_path: str) -> List[Dict[str, Any]]`: メイン解析処理（5年分）
  - `parse_single_year(root: etree._Element, year_type: str) -> Optional[Dict[str, Any]]`: 単一年度の解析
  - `validate_data(root: etree._Element) -> bool`: XBRL構造の妥当性検証
  - `extract_assets(root, contexts, year_type) -> Dict`: 資産項目抽出
  - `extract_liabilities(root, contexts, year_type) -> Dict`: 負債項目抽出
  - `extract_equity(root, contexts, year_type) -> Dict`: 純資産項目抽出
  - `calculate_metrics(assets, liabilities, equity) -> Dict`: 財務指標計算
  - `determine_consolidation(root, year_type) -> Optional[bool]`: 連結/単体判定
  - `get_period_end_date(root, year_type) -> Optional[date]`: 決算期末日の取得
- 対応年度:
  - CurrentYear（当期）
  - Prior1Year（前期）
  - Prior2Year（前々期）
  - Prior3Year（3期前）
  - Prior4Year（4期前）

### 3. EdinetFileManager（file_manager.py）
- BaseTempFileManagerを継承
- メソッド:
  - `create_temp_directory(doc_id: str) -> Path`: 一時ディレクトリ作成
  - `cleanup(path: Path) -> None`: ファイル削除
  - `find_xbrl_file(extract_dir: Path) -> Optional[str]`: XBRLファイル探索
  - `cleanup_old_files(days: int = 7) -> int`: 古いファイル削除

### 4. EdinetBalanceSheetService（service.py）
- 依存: AsyncSession, EdinetBalanceSheetRepository, EdinetDocumentFetcher, EdinetBalanceSheetParser, EdinetFileManager
- メソッド:
  - `fetch_and_save_single(doc_id: str, sec_code: str) -> List[EdinetBalanceSheetRead]`: 1件の書類を取得・解析・保存（5年分）
  - `upsert_balance_sheet(data: EdinetBalanceSheetCreate) -> EdinetBalanceSheetRead`: UPSERT処理
  - `get_latest_by_sec_code(sec_code: str) -> Optional[EdinetBalanceSheetLatest]`: 最新データ取得
  - `get_by_period(sec_code: str, period_end_date: date) -> Optional[EdinetBalanceSheetRead]`: 期間指定取得
  - `get_annual_data(sec_code: str, limit: int = 10) -> List[EdinetBalanceSheetRead]`: 年次データ取得
  - `get_multiple_latest(sec_codes: List[str]) -> List[EdinetBalanceSheetLatest]`: 複数銘柄の最新データ取得

## テスト計画
- 単体テスト: `tests/unit/services/market_data/edinet/balance_sheet/` 配下にテスト追加
- モック: EDINET API呼び出し、XBRLファイル読み込みはモック化

## 概要
EDINET から貸借対照表データを定期的に取得するバッチ処理を実装します。指定期間の有価証券報告書を検索し、各書類から5年分のデータを取得・保存します。

## 実装レイヤー
- [x] Batch 層

## 実装内容

1. `app/services/batch/fetch_edinet_balance_sheets.py` を作成
2. FetchEdinetBalanceSheetsクラスを実装:
   - クラス変数: `BATCH_TYPE = "edinet_balance_sheet_fetch"`
   - 依存: AsyncSession, BatchExecutionService, EdinetBalanceSheetService, EdinetDocumentFetcher
   - メソッド:
     - `execute(start_date: date, end_date: date) -> Dict`: バッチ実行
     - `_search_documents(start_date: date, end_date: date) -> List[Dict]`: 期間内の書類検索
3. バッチ処理フロー:
   - バッチ実行レコード作成（status='running'）
   - 書類一覧取得（期間内の全日付をループ）
   - 各書類を処理（fetch_and_save_single呼び出し）
     - 1つの書類から5年分のデータを取得・保存
     - 取得成功した年度数を集計
   - 10件ごとに進捗更新
   - 完了処理（status='completed'）
4. エラーハンドリング:
   - エラー時も処理継続（try-exceptで個別処理）
   - 構造化ログファイルに記録（`logs/edinet_processing/{date}.log`）
   - batch_executionsのfailed_stocksをインクリメント
