## 作業内容

### 1. 依存関係追加
`pyproject.toml` に以下を追加:
- `jinja2>=3.1.0` (FastAPIに含まれているが明示的に追加)
- `python-multipart>=0.0.5` (フォームデータ処理用)

### 2. ディレクトリ構造作成
app/
  templates/           (新規作成)
    admin/
      batch_trigger.html
  static/              (既存、拡張)
    css/
      admin.css        (新規作成)
    js/
      batch_trigger.js (新規作成)

### 3. FastAPIテンプレート設定 (`app/main.py` に追加)
- Jinja2Templatesインスタンス作成
- テンプレートディレクトリ設定: `app/templates`
- 静的ファイルマウント: `/static` → `app/static`

```python
from fastapi.templating import Jinja2Templates
from fastapi.staticfiles import StaticFiles

templates = Jinja2Templates(directory="app/templates")
app.mount("/static", StaticFiles(directory="app/static"), name="static")
```

### 4. 管理画面ルーター作成 (`app/api/admin/batch.py` 新規作成)
- `/admin/batch` エンドポイント（GET）
- テンプレートレンダリング

```python
from fastapi import APIRouter, Request
from app.main import templates

router = APIRouter(prefix="/admin", tags=["admin"])

@router.get("/batch")
async def batch_page(request: Request):
    return templates.TemplateResponse(
        "admin/batch_trigger.html",
        {"request": request}
    )
```

### 5. ルーター登録 (`app/main.py` に追加)
```python
from app.api.admin import batch
app.include_router(batch.router)
```

FastAPI標準のテンプレート機能を使い、最小限のバッチ実行UIを迅速に構築します。一時的な実装のため、シンプルさを優先します。

## 概要
Fetch APIまたはHTMXを使ってバッチAPIを呼び出し、レスポンスを画面に表示する機能を実装します。

## 詳細

### 実装内容

#### 1. JavaScript実装 (`static/js/batch_trigger.js`)

##### バッチ実行機能
```javascript
async function startBatch() {
  try {
    showLoading();
    const response = await fetch('/api/v1/batch/jpx-sequential/start', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' }
    });
    const data = await response.json();
    displayResult(data);
  } catch (error) {
    displayError(error);
  } finally {
    hideLoading();
  }
}
```

##### レスポンス表示機能
- JSON整形表示
- 成功/失敗の色分け
- エラーメッセージ表示

##### ステータス確認機能（オプション）
- ジョブIDでステータス取得
- `GET /api/v1/batch/status/{job_id}`

#### 2. HTMX実装（代替案）
HTMXを使う場合:
```html
<button hx-post="/api/v1/batch/jpx-sequential/start"
        hx-target="#result"
        hx-swap="innerHTML">
  バッチ実行
</button>
```

### 影響範囲

- `app/templates/admin/batch_trigger.html` (script読み込み追加)
