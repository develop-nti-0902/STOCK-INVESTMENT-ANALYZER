## 概要
FlaskアプリケーションからFastAPIのエンドポイントにHTTPリクエストを送信し、レスポンスを処理する機能を実装します。

## 詳細

### 実装内容

#### 1. FastAPI通信クライアント (`app/flask_app/fastapi_client.py`)
以下のメソッドを実装:

##### `health_check() -> dict`
- `GET http://localhost:8000/health`
- FastAPIの死活監視
- レスポンス: `{"status": "ok"}` または接続エラー

##### `fetch_single_stock(symbol: str, timeframe: str, start_date: str, end_date: str) -> dict`
- `POST http://localhost:8000/api/v1/batch/stock-data/single`
- 単一銘柄のデータ取得トリガ
- リクエストボディ:
  ```json
  {
    "symbol": "7203.T",
    "timeframe": "1d",
    "start_date": "2024-01-01",
    "end_date": "2024-12-31"
  }
  ```

##### `fetch_jpx_all_stocks(timeframe: str, start_date: str, end_date: str, market: str = None) -> dict`
- `POST http://localhost:8000/api/v1/batch/stock-data/jpx-all`
- JPX全銘柄の一括取得トリガ
- リクエストボディ:
  ```json
  {
    "timeframe": "1d",
    "start_date": "2024-01-01",
    "end_date": "2024-12-31",
    "market": "Prime"
  }
  ```

##### `get_batch_status(job_id: str) -> dict`
- `GET http://localhost:8000/api/v1/batch/status/{job_id}`
- バッチ実行ステータス取得

##### `get_batch_history(limit: int = 10) -> dict`
- `GET http://localhost:8000/api/v1/batch/history?limit={limit}`
- バッチ実行履歴一覧取得

#### 2. エラーハンドリング
- 接続エラー（FastAPI起動していない）
- タイムアウトエラー
- HTTPエラー（4xx, 5xx）
- JSONパースエラー
- エラーメッセージをフレンドリーに変換

#### 3. ルーティング追加 (`routes.py`)
以下のエンドポイントを追加:

##### `POST /api/fastapi/health`
- FastAPIヘルスチェック実行
- Ajax呼び出し用

##### `POST /api/batch/single`
- 単一銘柄取得リクエスト送信
- フォームデータ受け取り
- FastAPI呼び出し
- 結果をJSON返却

##### `POST /api/batch/jpx-all`
- JPX全銘柄取得リクエスト送信
- フォームデータ受け取り
- FastAPI呼び出し
- 結果をJSON返却

##### `GET /api/batch/status/<job_id>`
- バッチステータス取得
- Ajax呼び出し用

##### `GET /api/batch/history`
- バッチ履歴取得
- Ajax呼び出し用

#### 4. JavaScriptフロントエンド (`static/js/main.js`)
- ページ読み込み時にFastAPIヘルスチェック
- フォーム送信時のAjax処理
- レスポンス表示（JSON整形）
- エラー表示
- ローディング表示
- 定期的なステータス更新（ポーリング）

### 影響範囲
- `app/flask_app/fastapi_client.py` (新規作成)
- `app/flask_app/routes.py` (拡張)
- `app/flask_app/static/js/main.js` (新規作成)

### 技術的な考慮事項
- `requests` ライブラリ使用
- タイムアウト設定（10秒程度）
- リトライなし（シンプルに保つ）
- Ajax通信（fetch API使用）
- JSON整形表示

## 受け入れ条件
- [ ] FastAPI通信クライアントが実装されている
- [ ] 全メソッドが動作する
- [ ] エラーハンドリングが実装されている
- [ ] ルーティングが追加されている
- [ ] JavaScriptが実装されている
- [ ] ヘルスチェックが動作する

- [ ] ステータス取得が動作する
- [ ] 履歴取得が動作する
- [ ] レスポンスが正しく表示される

## 参考情報

- 参考資料:
  - requests: https://requests.readthedocs.io/
